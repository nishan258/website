# Luna KC — academic profile website

This is a static, single-page website adapted from **Prologue by HTML5 UP**. It is ready for GitHub Pages; no build step, package installation, server-side code, or CMS is required.

## Publish on GitHub Pages

1. Download and extract this ZIP.
2. Upload the **contents** of the extracted folder to the root of the target GitHub repository (the `index.html` file must be at the repository root, not inside another folder).
3. Commit the changes to the `main` branch.
4. In the repository, open **Settings → Pages** and select **Deploy from a branch**, branch `main`, folder `/(root)`.
5. Wait for the Pages deployment to complete, then use the published URL shown in Settings → Pages.

The site includes relative local paths for the stylesheet, scripts, and campus photograph, so it works as a GitHub Pages project site as well as a user site.

## Content and updates

- Main content is in `index.html`.
- Site-specific style adjustments are in `assets/css/site-overrides.css`.
- The Publications submenu interaction is in `assets/js/site.js`.
- The profile portrait is currently loaded from the public UNBC faculty-profile image URL. If that image URL changes, update both portrait `src` attributes in `index.html`.
- The campus photograph was retained from the previously supplied Luna KC website package.
- No domain-specific `CNAME` file is included. Keep the custom-domain configuration in GitHub Pages aligned with the domain you intend to use.
